WebRTC — проверка прямого соединения

GitHub Pages размещает только тестовую страницу. Сам DataChannel работает между браузерами. Режим TURN проверяет передачу через ретранслятор, если прямой маршрут не проходит.

Настройки TURN — одинаковые на Mac и iPhone

Нужны TURN-учётные данные от провайдера, например Metered. Не вставляйте сюда API secret от аккаунта — только TURN username и credential/password, выданные для ICE.

4. Короткий аудиотест


Mac отправит синусоидальный тон 440 Гц длительностью не более 5 секунд. Это проверяет аудиоканал, не передавая музыкальные файлы.






Сначала установите соединение: OFFER с Mac, ANSWER с iPhone.


5. Проверка настоящего MP3 (не более 10 секунд)


На Mac выбери локальный MP3-файл и нажми передачу. Сам файл не загружается на сайт и не отправляется как файл: в WebRTC передаётся только воспроизводимый звук. Передача автоматически остановится через 10 секунд. Для экономии лимита TURN не запускай тест многократно.







Создай OFFER на Mac и установи соединение. Затем выбери MP3-файл.
